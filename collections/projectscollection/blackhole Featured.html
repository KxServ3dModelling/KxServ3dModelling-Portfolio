Black Hole

A cinematic animation exploring a realistic black hole, gravitational lensing and an accretion disc rendered using Blender Cycles.

Software

Animation

Project Overview

This project began as an experiment to recreate the appearance of a scientifically inspired black hole. I focused on realistic lighting, volumetrics, gravitational lensing and cinematic camera movement while maintaining physically believable materials.

Animation

Project Breakdown

  • Created entirely in Blender.
  • Post-processing done in Davinci Resolve.
  • Rendered using Cycles. Render time: 18 Hours.
  • Procedural materials.
  • Volumetric lighting.
  • Rendered at 256 samples.
