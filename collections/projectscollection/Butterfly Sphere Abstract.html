Butterfly Sphere

A chromatic sphere stabbed with a balisong as butterflies surround it.

Renderer

Image

Project Overview

A single reference image from social media expanded into a beautiful capture of butterflies surrounding a sphere stabbed with a butterfly knife.

Project Breakdown

  • Created entirely in Blender.
  • Post-processing done in Davinci Resolve.
  • Rendered using Cycles. Render time: 13 Minutes.
  • Procedural materials.
  • Volumetric lighting.
  • Rendered at 2048 samples.
